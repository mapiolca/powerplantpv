# Checklist release v1.3 Maintenance

Cette checklist doit être déroulée sur une instance Dolibarr de recette avant publication.

## Préparation

- [ ] Le module est installé dans `htdocs/custom/powerplantpv`.
- [ ] La version du descripteur est `1.3.0`.
- [ ] `modulebuilder.txt` est présent.
- [ ] `ChangeLog.md` porte les notes `1.3.0`.
- [ ] `README.md` contient les liens vers les guides v1.3.
- [ ] Les guides utilisateur, administrateur, technique et release sont présents.

## Activation

- [ ] Activation OK.
- [ ] Désactivation OK si supportée par l'environnement.
- [ ] Réactivation OK.
- [ ] Aucun doublon de dictionnaire.
- [ ] Aucun doublon de modèle de rapport.
- [ ] Aucun doublon de modèle PDF `powerplantpvreport`.
- [ ] Les personnalisations de dictionnaires et modèles sont conservées.
- [ ] Les réglages par entité sont conservés.

## Droits

- [ ] Les droits `maintenance/read`, `maintenance/write`, `maintenance/delete`, `maintenance/report`, `maintenance/config` sont visibles.
- [ ] Un administrateur accède aux écrans maintenance.
- [ ] Un utilisateur lecture seule consulte sans modifier.
- [ ] Un utilisateur sans droit est refusé.
- [ ] Les droits Fichinter et PowerPlantPV sont bien combinés.

## Données par défaut

- [ ] Nature `PREVENTIVE_MAINTENANCE` présente.
- [ ] Modèle `preventive_maintenance` présent.
- [ ] Sections de base présentes.
- [ ] Champs de contrôle présents.
- [ ] Options de champs présentes.
- [ ] Prestations de maintenance présentes.
- [ ] Mappings prestation/section présents.

## Parcours fonctionnels

- [ ] Création d'une nature d'intervention.
- [ ] Création d'un modèle de rapport.
- [ ] Modification d'un modèle de rapport.
- [ ] Création ou modification d'une prestation de maintenance.
- [ ] Mapping prestation/section.
- [ ] Service actif avec prestations.
- [ ] Contrat lié à une centrale.
- [ ] Intervention liée à une centrale.
- [ ] Maintenance à prévoir.
- [ ] Maintenance en retard.
- [ ] Maintenance couverte par intervention clôturée ou signée.
- [ ] Mode `created` : brouillon, validée et facturée donnent `Programmée`.
- [ ] Mode `validated` : brouillon exclu, validée et facturée donnent `Programmée`.
- [ ] Une intervention clôturée ou signée reste prioritairement `Couverte`.
- [ ] Chevauchement aux bornes accepté et absence de chevauchement refusée.
- [ ] Multi-centrales.
- [ ] Multi-équipements.

## Rapports

- [ ] Onglet `Rapport` visible sur intervention.
- [ ] Snapshot créé au premier enregistrement.
- [ ] Sauvegarde brouillon OK.
- [ ] Sauvegarde finale OK.
- [ ] Recalcul avant verrouillage OK.
- [ ] Conservation des valeurs par clé stable OK.
- [ ] Verrouillage après clôture OK.
- [ ] Verrouillage après signature OK.
- [ ] Mesures DC générées depuis la topologie.
- [ ] Mesures DC manuelles possibles sans topologie.
- [ ] Fichiers de rapport uploadés et supprimés avec token.

## PDF

- [ ] Modèle Fichinter `powerplantpvreport` visible.
- [ ] Génération PDF sans rapport existant.
- [ ] Génération PDF avec rapport complet.
- [ ] Multi-centrales dans le PDF.
- [ ] Multi-équipements dans le PDF.
- [ ] Mesures DC dans le PDF.
- [ ] Relevés N-1/N dans le PDF.
- [ ] Signatures/fichiers affichés lorsque présents.
- [ ] Aucun chevauchement de pied de page.

## Production et consommation

- [ ] Onglet `Production/consommation` visible sur centrale.
- [ ] Saisie manuelle d'un relevé.
- [ ] Delta avec relevé précédent.
- [ ] Synchronisation depuis rapport enregistré.
- [ ] Pas de doublon après nouvelle sauvegarde du même rapport.
- [ ] Brouillon/recalcul ne publie pas de relevé provisoire actif.

## Calendrier et statistiques

- [ ] Liste maintenance filtrable.
- [ ] Calendrier mensuel OK.
- [ ] Année de référence et horizons 2/3 ans fonctionnels.
- [ ] Comparatif annuel et courbes mensuelles cohérents.
- [ ] Tableaux comparatifs par centrale et client triés sur le total.
- [ ] Comparatif par nature limité aux dix principales natures, avec `Autres` si nécessaire.
- [ ] Années sans intervention et limites décembre/janvier vérifiées.
- [ ] Intervention liée plusieurs fois comptée une seule fois dans les totaux globaux.
- [ ] Statut `Programmée` visible dans la liste, le calendrier et la fiche centrale.
- [ ] Statistiques comparatives vérifiées sur deux et trois années civiles, avec cohérence entre totaux annuels, courbes mensuelles et répartitions.
- [ ] Tri centrale, tiers, contrat, récurrence, période, intervention, statut et environnement avant pagination.
- [ ] Changement de limite 20/50/100 avec filtres et tri conservés.

## Rappels automatiques

- [ ] Envoi SMTP réel hebdomadaire et mensuel.
- [ ] Hebdomadaire : J+6 inclus et J+7 exclu.
- [ ] Mensuel : J+29 inclus et J+30 exclu.
- [ ] Les retards historiques sont inclus hors fenêtre.
- [ ] Anti-doublon par destinataire, fréquence et occurrence.
- [ ] Rattrapage après plusieurs semaines/mois sans rafale d'envois.
- [ ] Destinataires FR/EN : textes dynamiques, statuts et dates dans la langue utilisateur.
- [ ] Liens absolus fonctionnels vers centrale, contrat et intervention.
- [ ] Échec SMTP partiel : seuls les destinataires en échec sont réessayés.
- [ ] Échec d'écriture d'un marqueur : retour cron négatif et log sans adresse en clair.
- [ ] Échec de reprogrammation : retour cron négatif et marqueurs réussis conservés.
- [ ] Deux entités exécutées simultanément utilisent des verrous distincts.
- [ ] Les réglages et marqueurs utiles sont conservés après désactivation/réactivation.

## Multicompany

- [ ] Données de l'entité A isolées de l'entité B.
- [ ] Dictionnaires par entité OK.
- [ ] Modèles par entité OK.
- [ ] Documents générés dans le répertoire de l'entité propriétaire.
- [ ] Objet partagé consulté depuis une autre entité sans fuite documentaire.

## Contrôles techniques

- [ ] `php -l` OK sur tous les fichiers PHP.
- [ ] `composer validate --strict` OK.
- [ ] PHPStan exécuté si disponible dans l'environnement Dolibarr parent.
- [ ] Aucune erreur PHP visible dans les logs Dolibarr pendant la recette.
- [ ] Aucun warning bloquant lors des pages maintenance.
- [ ] Aucun token CSRF manquant sur les actions sensibles.

## Documentation

- [ ] Guide utilisateur relu.
- [ ] Guide administrateur relu.
- [ ] Vue technique relue.
- [ ] Checklist release complétée.
- [ ] Notes de migration lues par l'administrateur.
