# PR8 - Multi-centrales, équipements et mesures DC

## Objectif

PR8 étend le rapport d'intervention sans finaliser le PDF. Le moteur produit désormais un rapport groupé par centrale, répète les sections liées aux équipements installés et génère les mesures DC depuis une configuration MPPT / entrées PV propre à l'installation.

Le PDF complet reste hors périmètre et sera traité dans PR10.

## Données ajoutées

Configuration installée sur la centrale :

| Table | Rôle |
|---|---|
| `powerplantpv_equipment_mppt` | MPPT configurés sur une ligne onduleur installée (`powerplantpv_powerplantcomp.rowid`) |
| `powerplantpv_equipment_string` | Entrées PV et strings raccordés par onduleur, MPPT et entrée PV |

Mesures de rapport :

| Table | Rôle |
|---|---|
| `powerplantpv_report_dc_measure` | Lignes de mesures DC figées dans le rapport, avec clé stable de recalcul |

Le snapshot équipement `powerplantpv_report_equipment` conserve aussi les informations utiles au rapport : équipement source, type, libellé, marque, modèle, référence produit, numéro de série, position et snapshot technique JSON.

## Génération du rapport

Le moteur commence par rattacher les prestations aux centrales :

- contrats liés directement aux centrales en priorité ;
- contrats liés uniquement à l'intervention en fallback, dupliqués par centrale seulement si aucune centrale n'a de contrat propre ;
- sélection manuelle du service de maintenance en dernier recours, également portée par centrale.

Les sections optionnelles sont ensuite évaluées pour la centrale concernée. Les sections d'équipement ne sont répétées que pour les équipements installés de cette centrale.

## Mesures DC

Quand la prestation `DC_ELECTRICAL_MEASURE` est active, le rapport crée une section DC par centrale. Dans chaque section :

1. les onduleurs installés sont lus depuis `powerplantpv_powerplantcomp` ;
2. les MPPT sont lus depuis `powerplantpv_equipment_mppt` ;
3. les entrées PV sont générées selon `pv_input_count` ;
4. les informations de string raccordé sont superposées depuis `powerplantpv_equipment_string`.

Chaque ligne `powerplantpv_report_dc_measure` porte :

- centrale et onduleur source ;
- snapshot onduleur : référence, libellé, numéro de série ;
- MPPT et entrée PV ;
- référence string et raccordement ;
- tension à vide, polarité, isolement et observation.

La clé stable suit la topologie installée. Lors d'un recalcul avant signature/clôture, les valeurs saisies sont recopiées si la clé stable existe toujours.

## Mode manuel

Si aucune configuration MPPT / entrée PV n'existe, la section DC affiche un mode manuel non bloquant. L'utilisateur peut enregistrer le rapport puis ajouter des lignes de mesure DC manuelles.

Les lignes manuelles sont conservées au recalcul grâce à une clé stable rattachée à l'occurrence de section.

PR8 n'implémente pas l'option facultative d'enregistrement automatique de cette configuration dans la fiche centrale depuis le rapport.

## Interface centrale

L'onglet composition d'une centrale permet de gérer la configuration MPPT / strings sur les lignes d'équipement identifiées comme onduleurs :

- ajout ou mise à jour d'un MPPT ;
- suppression d'un MPPT et de ses strings ;
- ajout ou mise à jour d'une entrée string ;
- suppression d'une entrée string ;
- préremplissage non destructif depuis les caractéristiques produit onduleur.

Les caractéristiques produit restent une aide de saisie. La source de vérité du raccordement installé est la configuration de centrale.

## Verrouillage

Les rapports restent en lecture seule lorsque l'intervention est signée ou clôturée. Les lignes DC spécialisées suivent le même verrouillage que les champs génériques.

## Tests fonctionnels attendus

- intervention avec une centrale ;
- intervention avec deux centrales et prestations différentes ;
- centrale avec deux onduleurs ;
- onduleur avec 2 MPPT et 2 entrées PV par MPPT : 4 lignes DC générées ;
- deux onduleurs avec topologies différentes : total correct ;
- absence de configuration MPPT : bloc manuel affiché ;
- ajout manuel de ligne DC puis sauvegarde ;
- recalcul avant signature : conservation des valeurs par clé stable ;
- intervention signée ou clôturée : lecture seule ;
- modification ultérieure de la fiche centrale : snapshot existant inchangé.
