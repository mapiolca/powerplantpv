# PR5 - Menu Maintenance global

## Objectif

PR5 ajoute l'accès global aux maintenances depuis le menu haut `Centrale PV` :

- `Maintenance`
- `Nouvelle intervention`
- `Liste des maintenances`
- `Calendrier des maintenances`
- `Statistiques des maintenances`

Le périmètre ne crée pas de table et ne modifie pas le core Dolibarr. Les interventions restent des fiches interventions natives.

## Sources de données

Les pages globales réutilisent le moteur PR4 `PowerPlantPVMaintenanceScheduler`.

La méthode `getMaintenanceRows()` agrège les maintenances calculées depuis :

- les centrales visibles dans `getEntity('powerplant')` ;
- les contrats liés via `element_element` ;
- les services actifs de contrat ;
- les prestations de maintenance portées par les produits/services ;
- les interventions liées aux centrales ;
- les natures d'intervention marquées maintenance.

Les statuts restent ceux de PR4 : `planned`, `due`, `overdue`, `covered`, `not_required` et `incomplete`.

## Pages ajoutées

### `maintenance_intervention_card.php`

Page d'aiguillage pour la création guidée d'une intervention de maintenance.

Elle permet de sélectionner :

- une ou plusieurs centrales ;
- un contrat ;
- une nature d'intervention.

Elle accepte `fk_powerplant`, `powerplantpv_powerplants[]`, `fk_contract`, `fk_contrat` et `contratid`, puis redirige vers `fichinter/card.php?action=create` avec les paramètres déjà traités par les hooks PR3/PR4.

### `maintenance_list.php`

Liste globale calculée des maintenances.

Colonnes :

- centrale ;
- tiers ;
- contrat ;
- services actifs ;
- prestations ;
- récurrence ;
- période ;
- dernière intervention couvrante ;
- statut ;
- action de création d'intervention.

Filtres :

- centrale ;
- tiers ;
- statut ;
- période début/fin ;
- nature d'intervention ;
- prestation.

### `maintenance_calendar.php`

Première vue calendrier mensuelle simple.

Elle affiche les maintenances prévues, en cours et en retard, avec navigation mois précédent / mois suivant, liens vers centrale et contrat, et action de création d'intervention.

Cette PR ne crée pas d'événements Agenda supplémentaires.

### `maintenance_stats.php`

Première page d'indicateurs.

La période est filtrable et vaut l'année courante par défaut.

Indicateurs :

- maintenances à prévoir : `planned + due` ;
- maintenances en retard : `overdue` ;
- maintenances couvertes : `covered` ;
- maintenances non requises : `not_required`.

Les lignes `incomplete` restent visibles dans la liste mais ne sont pas comptées dans ces quatre indicateurs.

Répartitions :

- par nature d'intervention ;
- par centrale ;
- par client.

## Droits

Les menus et pages utilisent :

- `powerplantpv->maintenance->read` pour la lecture, la liste, le calendrier et les statistiques ;
- `powerplantpv->maintenance->write` pour la création guidée d'intervention ;
- le droit natif `ficheinter->creer` pour accéder à la création effective d'intervention ;
- le droit natif contrat en lecture lorsque les contrats doivent être affichés.

Le helper central `powerplantpvUserHasMaintenanceRight()` conserve le bypass administrateur Dolibarr.

## Limites

- Pas de génération PDF.
- Pas d'onglet Rapport complet.
- Pas de création d'événement Agenda.
- Les périodes couvertes sont avancées automatiquement d'un seul intervalle depuis la récurrence du contrat ; les récurrences `custom` restent manuelles.
- Les statistiques sont une première version tabulaire sans graphique externe.

- Vérifier que le menu est absent sans droits maintenance.
- Vérifier que `Nouvelle intervention` est visible avec `maintenance->write` et le droit natif de création intervention.
- Créer une intervention depuis la page guidée avec centrale, contrat et nature préremplis.
- Vérifier les filtres de `maintenance_list.php`.
- Vérifier l'action de création depuis une ligne de liste.
- Vérifier la navigation mois précédent / suivant du calendrier.
- Vérifier les liens centrale et contrat dans le calendrier.
- Vérifier les compteurs de `maintenance_stats.php` sur une période contenant des maintenances prévues, en retard, couvertes et non requises.
