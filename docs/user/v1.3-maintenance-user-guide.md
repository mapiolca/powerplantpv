# Guide utilisateur v1.3 Maintenance

Ce guide décrit le parcours métier de maintenance préventive fourni par PowerPlantPV 1.3. Il suppose que le module est activé, que les droits maintenance sont attribués et que les modèles par défaut ont été installés par l'administrateur.

## Préparer les prestations de maintenance

Une prestation de maintenance est portée par un service Dolibarr associé à une ou plusieurs prestations PowerPlantPV.

1. Ouvrir la fiche du produit ou service Dolibarr vendu dans le contrat de maintenance.
2. Dans les champs complémentaires PowerPlantPV, renseigner les prestations de maintenance applicables, par exemple contrôle visuel, mesure DC, relevés de production ou thermographie.
3. Enregistrer le produit ou service.
4. Utiliser ce service dans les contrats clients qui couvrent les centrales photovoltaïques.

Les prestations actives déterminent les sections du rapport d'intervention. Un service sans prestation de maintenance ne déclenche pas de rapport préventif spécifique.

## Configurer un service dans un contrat

1. Créer ou ouvrir un contrat client Dolibarr.
2. Ajouter une ligne de service correspondant à la maintenance.
3. Activer le service dans le contrat.
4. Renseigner les champs complémentaires de maintenance du contrat :
   - récurrence ;
   - début de la prochaine période ;
   - fin de la prochaine période.
5. Lier le contrat à la centrale concernée avec les liens natifs Dolibarr.

Le statut de maintenance est calculé depuis les services actifs, les prestations attachées aux produits/services, la période configurée et les interventions déjà liées.

## Lier un contrat à une centrale

Depuis la fiche centrale ou la fiche contrat, utiliser les liens natifs Dolibarr pour associer le contrat et la centrale. Le module lit ces liens pour afficher :

- les contrats liés dans l'onglet `Maintenance` de la centrale ;
- les services actifs ;
- les prestations couvertes ;
- le statut de prochaine maintenance.

Un contrat non lié à une centrale ne peut pas alimenter le planning de cette centrale.

## Créer une intervention de maintenance

Trois entrées sont prévues :

- onglet `Maintenance` d'une centrale ;
- menu PowerPlantPV `Maintenance` ;
- calendrier de maintenance.

Le bouton de création prépare une intervention Dolibarr avec la centrale, le contrat, le client, le projet et la nature d'intervention lorsque ces informations sont disponibles.

Après création dans Dolibarr, vérifier que l'intervention est bien liée à la centrale et au contrat. Ces liens servent au rapport, au calendrier et au statut couvert.

## Remplir un rapport d'intervention

1. Ouvrir la fiche de l'intervention.
2. Aller dans l'onglet `Rapport`.
3. Vérifier les messages affichés en haut du rapport.
4. Renseigner les sections générées depuis le modèle actif.
5. Sauvegarder en brouillon si la saisie n'est pas terminée.
6. Enregistrer pour finaliser les valeurs du rapport.

Au premier enregistrement, PowerPlantPV crée un snapshot du rapport. Les changements ultérieurs du modèle ne modifient pas ce snapshot, sauf recalcul volontaire avant verrouillage.

## Recalculer un rapport

Le recalcul est disponible uniquement avant clôture ou signature de l'intervention.

Il recharge le modèle, les prestations actives, les centrales et les équipements, puis conserve les valeurs déjà saisies lorsque les clés stables correspondent encore. Les rapports signés ou clôturés sont en lecture seule.

## Signer ou clôturer

La signature ou la clôture se fait avec les mécanismes natifs de l'intervention Dolibarr.

Après signature ou clôture :

- l'onglet `Rapport` reste consultable ;
- les champs ne sont plus modifiables ;
- le recalcul est bloqué ;
- les fichiers et mesures du rapport sont conservés.

Une intervention clôturée ou signée peut couvrir une période de maintenance si elle correspond à la centrale, au contrat et à la nature de maintenance attendus.

## Générer le PDF

1. Ouvrir l'intervention.
2. Utiliser le bloc natif `Fichiers joints`.
3. Sélectionner le modèle `powerplantpvreport` pour les interventions.
4. Cliquer sur `Générer`.

Le PDF lit le snapshot existant. Il ne crée pas de rapport et ne recalcule pas les données. Si aucun rapport n'existe, le PDF reste générable avec un contenu minimal.

## Consulter production et consommation

Sur la fiche centrale, l'onglet `Production/consommation` affiche les relevés d'index.

Les relevés peuvent venir :

- d'une saisie manuelle ;
- d'un rapport d'intervention enregistré, via les champs de production/consommation.

Les valeurs `N-1` du rapport sont préremplies depuis le dernier relevé actif connu pour la centrale et le type de relevé concerné. Les doublons issus d'un même rapport sont évités par une clé de source.

## Consulter calendrier et statistiques

Le menu PowerPlantPV `Maintenance` donne accès à :

- la liste des maintenances ;
- le calendrier mensuel ;
- les statistiques.

La liste et le calendrier affichent les maintenances à prévoir, dues ou en retard selon les périodes configurées. Les statistiques agrègent les états par période, centrale, client et nature.

## Points de contrôle utilisateur

- La centrale possède un tiers.
- Le contrat est lié à la centrale.
- Le service du contrat est actif.
- Le produit/service du contrat porte une prestation de maintenance.
- La période de maintenance est renseignée.
- L'intervention est liée à la centrale et, si possible, au contrat.
- Le rapport est enregistré avant génération du PDF complet.
